# Exemple de configuration d'un routeur pour la configuration des ports

L'accès externe de la passerelle Simplicollect exige l'ouverture de "ports" TCP/IP sur votre routeur.

Bien que chaque marque et modèle de routeur a une procédure de configuration qui lui est propre, nous vous proposons un exemple avec un routeur D-Link afin de vous aider la cette procédure.
