# Security

To access the function, click the Security button on the home page of the Configuration section.<br>![Screenshot](../../assets-en/securite/image2020-2-9-21-35-13.png){ width=600 }

Using SimpliCollect requires an account and a password in order to secure the use of the application.

![Screenshot](../../assets-en/securite/security-main.png){ width=850 }

## Step-by-step guide

The functions for configuring security are as follows:

## Navigation

1.  From the SimpliCollect main menu, click Security;
2.  Then click Users; the user management interface will appear;<br>![Screenshot](../../assets-en/securite/security-nav-1.png){ width=800 }

## Create a user account

1.  Click the **Add User +** button;<br>![Screenshot](../../assets-en/securite/image2020-1-31-17-4-37.png){ width=500 }
2.  Enter the user's first name and last name;<br>![Screenshot](../../assets-en/securite/security-add-user.png){ width=1024 }
3.  Enter the user name (no French characters);
4.  Enter the password and its confirmation;
5.  Adjust the accesses that the user will have rights to;
6.  Save the new user by clicking the **Save** button.

## Deactivate a user account

You can deactivate a user's account so that they can no longer access the system, without destroying their account.

1.  Choose the user account in the list at the top of the display;<br>![Screenshot](../../assets-en/securite/security-deactivate.png){ width=603 }
2.  Uncheck the Active box in the user's parameters;<br>![Screenshot](../../assets-en/securite/security-deactivate-2.png){ width=500 }
3.  Click the **Save** button.

## Delete a user account

You can delete a user account completely.

1.  Choose the user account in the list at the top of the display;
2.  Click the **Delete** button and click Yes at the confirmation message;<br>![](../../assets-en/securite/image2020-1-31-17-19-59.png)<br>![Screenshot](../../assets-en/securite/image2020-1-31-17-21-0.png){ width=800 }
3.  The user will be completely removed from the system.
