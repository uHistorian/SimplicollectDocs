# MaestrEau - Utilisation

Il est possible de gérer toutes les opérations d'irrigation et de gestion de vos cultures à partir des différentes applications MaestrEau.

Que ce soit sur votre PC ou Mac, votre téléphone intelligent ou votre tablette, les applications MaestrEau vous donne tous les outils pour gérer vos opérations.

L'administrateur de système doit avoir prélablement configurer les Aires, les Zone et les Scénarios d'opération.  Voir la section [Confguration - MaestrEau](../maestreau-configuration/index.md) pour les explications sur les principes de fonctionnement.

Votre compte d'utilisateur vous donne accès aux différentes fonctions:

- MaestrEau sur Web:
- MaestrEau sur iPhone
- MaestrEau sur Android

Consultez les sections sous MaestrEau - Opérations pour les instructions d'utilisation des différents outils de gestion.
