# MaestrEau sur iPhone

SC-MaestrEau est disponible sur la plate forme iPhone d'Apple.  L'application fonctionne en mode "léger" et permet de faire certaines fonctions dont l'activation/désactivation, la configuration du mode Pluie, l'ouverture, la fermeture ou le cyclage d'un Programme donné ainsi qu ela visualisation des données d'un Tag attaché à une Zone.

## Guide étape par étape

Les fonctions de l'application sont les suivantes:

## Installation à partir du App Store

La première étape dans l'utilisation de MaestrEau sur votre iPhone est l'installation à partir du App Store d'Apple.

1.  Cliquer l'icône AppStore sur votre iPhone, cliquer sur le mode Rechercher et taper "simplicollect maestreau" pour trouver l'application:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-10-39-42.png){ width=250 }
2.  Cliquer sur le bouton Installer afin de charger et installer l'application:
3.  Lorsque l'installation est terminée, cliquer sur le bouton Démarrer pour exécuter l'application:

## Paramètres de connexion

La première fois que vous actionner l'application, il faut remplir les champs qui vous permettront <br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-10-41-25.png){ width=250 }

1.  Entrez l'adresse url de la passerelle SimpliCollect dans le champ Passerelle.  Cette adresse vous sera donnée par l'administrateur SimpliCollect;

    !!! info

        On peut avoir deux types de connexion: locale ou via Internet. Dans le cas de la connexion locale, on va insérer l'adresse IP de la passerelle ainsi que le numéro du port d'accès. Dans le cas d'une connexion via Internet, on va entrer le nom du site pour se connecter à la passerelle SimpliCollect. Ces renseignements vous seront donnés par votre administrateur de système.

2.  Entrez le numéro du port d'accès de données de la passerelle (4 ou 5 chiffres) qui vous est donné par l'administrateur Simplicollect;

3.  Dans le champ suivant, entrez votre code d'utilisateur qui vous a été attribué par l'administrateur SimpliCollect;

4.  Finalement, entrez votre mot de passe qui vous a également été attribué par l'administrateur SimpliCollect;

5.  Lorsque tous les champs sont entrés, vous êtes prêt à vous connecter:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-10-47-20.png){ width=250 }

6.  cliquez sur le bouton Login et l'application établira la connexion à la passerelle (délais de 2 à 10 secondes);

7.  Un message de bienvenue apparait en dessous du bouton Login et vous dirigera vers l'affichage principal de l'application;

8.  Un message d'erreur peut également apparaitre sur l'affichage de connexion.  Dans ce cas, lire attentivement le message et suivre les instructions.  Dans la plupart des cas, une erreur s'est glissée dans les paramètres de connexion.  Corrigez l'erreur et cliquez de nouveau sur le bouton Login.  Si l'erreur persiste, faite à appel à votre administrateur SimpliCollect.

    !!! info

        Tous les paramètres de connexion sont sauvegardés sur votre iPhone et vous n'aurez pas besoin de les entrer de nouveau la prochaine fois que vous exécutez l'application.

## Navigation

Lorsque l'application est connectée à la passerelle SimpliCollect, vous aurez accès à l'affichage principal de l'application.  <br>La première étape est de choisir une Zone.

1.  Cliquer sur le bouton Choisir Zone qui fera apparait la liste des Zones disponible triée par numéro de Zone;<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-10-49-48.png){ width=250 }

2.  Naviguez dans la liste et cliquez sur la Zone que vous désirez observer (peut prendre quelques secondes);<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-10-50-50.png){ width=250 }

    !!! info

        Les zones en vert indiquent que la zone est active, les zones en rouges indiquent qu'elles sont en mode "pluie" et les zones en blanc sont inactives.

3.  L'application charge les paramètres de la Zone et vous retourne à l'écran principal qui vous montre tous les paramètres de la Zone, le Scénario actif et ses Programmes;<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-11-18-00.jpg){ width=350 }

4.  On peut choisir un Programme (1) et cliquer sur le bouton Détails Prog. (2) afin de visualiser les paramètres de ce Programme:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-11-26-25.png){ width=250 }

5.  Cet écran donne tous les détails de configuration du Programme (Type, début, arrêt, etc.).  On peut changer la valeur des champs du programme de contrôle et cliquant dans le champ et en inscrivant la nouvelle valeur:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-11-29-26.png){ width=250 }

6.  Pour changer les jours d'application du Programme, cliquer sur l'icône à côté du champ Jours pour voir apparait les jours de la semaine a sélectionner

7.  Dans l'écran, cliquer sur les jours (1) pour voir apparaitre/disparaitre le X de la case.  Cliquer que la flèche Arrière (2) pour retourner à l'écran précédent:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-11-30-8.png){ width=250 }

8.  Cliquer sur la flèche MaestrEau pour retourner à l'écran principal;

9.  Dans les paramètres de la Zone, on peut également voir le numéro de l'actuateur (i.e. le relais qui contrôle la valve, le commutateur, etc.) et sont mode:<br>![](../../assets/maestreau-sur-iphone/2018-05-30-11-36-18.jpg)<br>
    1.  Rouge:  L'actuateur est toujours fermé
    2.  Vert:  L'actuateur est toujours ouvert
    3.  Turquoise: L'actuateur est en mode automatique et répond aux commandes de MaestrEau

10. On peut également voir l'état actuel de l'actuateur (ouvert=vert /fermé=rouge) ainsi que le temps de la dernière action sur l'actuateur;<br>![](../../assets/maestreau-sur-iphone/2018-05-30-11-36-18.jpg)

11. On peut voir le Tag, la valeur de ce dernier et l'horodatage de la dernière valeur lue dans le cas où un Tag est attaché à la Zone;<br>![](../../assets/maestreau-sur-iphone/2018-05-30-11-36-18.jpg)

## Visualisation

Dans le cas des types contrôle par cible, un tag est associé à la zone et la valeur courante du tag est comparée à la consigne de contrôle afin d'activer l'actuateur.  On peut visualiser les données du tag pour les dernières heures à partir de l'application mobile afin de constater ce qu'il en est:

1.  Cliquer sur le bouton Graphique de données situé en base de l'écran:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-11-42-57.jpg){ width=350 }
2.  Un graphique apparaît et donne les données des deux dernières heures:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-11-44-52.png){ width=250 }
3.  On peut changer la fenêtre de temps en choisissant une des trois plages:  2h, 8h et 24h:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-11-46-42.png){ width=250 }
4.  Les données apparaissent dans le graphique (2) et on peut en rafraichir le contenu en cliquant sur le bouton Rafraichir (3);
5.  Cliquer sur la flèche MaestrEau pour retourner à l'écran principal.

## Activer une Zone

Il est possible d'activer ou de désactiver une zone afin que les programmes de contrôle soit actif ou en suspens.

1.  Dans l'écran principal de la zone, déplacer le bouton **Activé** vers la gauche afin de désactiver la zone:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-22-47.jpg){ width=350 }
2.  L'application demande de confirmer l'action... Répondre Oui afin de procéder;
3.  La zone est désactivée au plus aucune opération de contrôle n'est faite sur la zone;
4.  Pour activer la zone, déplacer le bouton **Activé** vers la droite afin de désactiver la zone:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-26-23.jpg){ width=350 }
5.  La zone est alors active et le bouton passe au vert:
6.  L'application demande de confirmer l'action... Répondre Oui afin de procéder;
7.  La zone est activée et les programmes du scénario actif seront appliqués:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-28-24.jpg){ width=350 }

## Mode Pluie

L'application du mode Pluie à une zone, surtout utilisé en irrigation, "suspend" les opérations de contrôle sur la zone pour une période de temps donnée.  Lorsque la période établie est à échéance (c.-à-d. lorsque la période de pluie est terminée), les opérations de contrôle de la zone reprennent.

1.  Dans l'écran principal de la zone, déplacer le bouton **Pluie** vers la droite afin d'activer le mode:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-26-23.jpg){ width=350 }
2.  L'application demande de confirmer l'action... Répondre Oui afin de procéder;
3.  Un affichage apparait et demande d'indiquer le moment de la reprise des opérations de contrôle sur la zone.  Inscrire la date et l'heure de la reprise:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-15-35-37.png){ width=250 }
4.  Lorsque choisi, cliquer sur la flèche MaestrEau pour retourner à l'écran principal et le mode Pluie est activé sur cette zone.  Le commutateur Pluie passe au vert:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-37-02.jpg){ width=350 }
5.  La zone reprendra ses activités à l'échéance de la date/heure spécifiée;
6.  On peut annuler en tout temps le mode Pluie... Pour ce faire, déplacer le bouton vers la gauche afin de désactiver le mode:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-37-02.jpg){ width=350 }
7.  L'application demande de confirmer l'action... Répondre Oui afin de procéder;
8.  Un message confirme que le mode Pluie sur cette zone est désactivé.

## Changer de scénario actif

Une zone peut avoir plusieurs scénarios de contrôle pour appliquer différents modes de contrôle et **un seul scénario peut être actif**.  On peut changer de scénario actif à partir de l'application.

1.  Dans l'écran principal de la zone, cliquer dans le champ Scénario et une liste déroulante des scénarios configurés à la zone apparait en bas de page:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-15-43-48.png){ width=250 }
2.  Choisir dans la liste déroulante le scénario (2) voulu et cliquer sur OK (3);
3.  Le nouveau scénario apparait dans le champ et un message confirme le changement de scénario;
4.  Les programmes du nouveau scénario actif apparaissent dans l'écran principal et sont mis en action:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-15-47-21.png){ width=250 }

## Opérations Manuelles sur la Zone

L'application permet également de faire des opérations manuelles sur une zone **active **tel qu'**ouvrir**, **fermer**, **arrêter** et remettre en mode **automatique**.

1.  Dans l'écran principal de la zone, cliquer sur l'icône d'engrenage en bas à gauche de l'affichage ou cliquer directement dans le champ mode de l'écran:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-15-52-40.jpg){ width=300 }

2.  Un dialogue apparait et propose les différentes options qui peuvent s'appliquer à contrôle:<br>![](../../assets/maestreau-sur-iphone/image2018-5-30-15-55-10.png)

3.  Choisir une des options pour activer l'actuateur selon le mode de contrôle de la zone (c.-à-d. Séquence, Séquence+Cible, Cible, ON/OFF, Volet, Manuel);

    !!! info

        Pour les différentes options sur les modes de contrôle, voir la documentation de MaestrEau pour Windows en [cliquant sur ce lien.](maestreau-web/operations.md)

## Déconnexion

Lorsque vous avez terminé avec l'application:

1.  Cliquer sur le bouton déconnexion situé dans le coin inférieur droit de l'écran:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/2018-05-30-11-12-24.jpg){ width=250 }
2.  On est de retour à l'écran d'accueil pour se connecter au système à nouveau:<br>![Capture d’écran](../../assets/maestreau-sur-iphone/image2018-5-30-10-47-20.png){ width=200 }
